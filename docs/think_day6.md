Task 6 - Think for yourself

Question: Which department would you check first after a dip: the biggest, or the one that changed most? Why?

Answer: 
I will not check the biggest department first. I will check the department which changed the most.
Because the biggest department is large so its effect will always look big. But the department which suddenly dropped a lot must have some real problem - like manager issue, workload is high, or people morale is low. We need to find that reason.
